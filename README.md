# Responsive Internship Board

A beginner-friendly responsive internship listing website built using HTML, CSS, JavaScript, and JSON.

## 📌 Project Overview

The Responsive Internship Board allows users to browse internship opportunities and easily find internships based on their title, domain, location, mode, or skills.

The website is designed to work on desktop, tablet, and mobile screen sizes.

## ✨ Features

- View available internship opportunities
- Search internships by:
  - Internship title
  - Domain
  - Location
  - Mode
  - Skills
- Filter internships by domain
- Display internship cards dynamically using JSON data
- View internship details using the "View Details" button
- Empty state when no internship matches the search
- Error state when internship data cannot be loaded
- Keyboard-friendly form controls
- Accessible labels for search and filter controls
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- VS Code
- Live Server
